# 悬浮提词

一个原生 Android 悬浮提词器原型，面向直播、口播、录课和视频拍摄场景。

当前版本包含：

- 匀速滚动 / AI 跟随模式切换入口
- 台词编辑、字数统计、字号、速度、颜色与循环播放设置
- 系统级悬浮窗，支持顶部六点拖拽移动
- 右下角拖拽缩放，点击台词区域播放/暂停，底部复位
- 前台通知，方便切换到相机、抖音等其他应用继续使用

当前版本先完成悬浮提词的视觉与基础操控闭环；“AI 跟随”已提供模式入口，真实语音识别/跟读定位需要接入 SpeechRecognizer 或后续的 AI 服务。

在 Android Studio 中打开项目根目录，等待 Gradle 同步后运行 `app`。首次点击“打开悬浮提词”会跳转到系统设置，需要允许“显示在其他应用上层”。
